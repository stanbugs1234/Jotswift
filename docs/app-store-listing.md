## App Privacy (the "nutrition label")

**Do you or your third-party partners collect data from this app?** Yes.
**Is any of it used for tracking?** No. **Is it linked to the user?** Yes, all
of it.

| Data type | Collected | Purpose |
|---|---|---|
| Contact Info → Email Address | Yes | App Functionality |
| Contact Info → Name | Yes | App Functionality |
| User Content → Audio Data | Yes | App Functionality |
| User Content → Photos or Videos | Yes | App Functionality |
| User Content → Other User Content | Yes | App Functionality |
| Identifiers → User ID | Yes | App Functionality |
| Purchases → Purchase History | Yes | App Functionality |

Everything else (location, health, browsing, diagnostics, usage data,
advertising): **not collected**. This matches `ios/Runner/PrivacyInfo.xcprivacy`.

## App Review notes

```
An account is needed because notebooks, tasks and events sync between the
user's iPad, iPhone and the web, and purchases follow the account. Sign in
with Apple works for review. Purchases can be tested with a sandbox
account: Settings → Jotswift Pro shows the subscriptions and lifetime
purchase; Settings → Restore purchases restores them. Account deletion is in
Settings → Delete account. Custom planners (New notebook → Build your own)
need Pro.
```
